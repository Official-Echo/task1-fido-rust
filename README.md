# Реалізація завдання на Rust

Виконання Завдання 1 для FIdo: знайти вузол на позиції ⌊2n/3⌋ - 1 в однозв'язному списку.

Основна частина це бібліотека `src/lib.rs`, крейт `node_task`. До неї додатково створена консольна програма `src/main.rs`, яка працює через підключення окремого feature `cli`, через що сама бібліотека не має залежностей.

## Вхідні дані

Якщо не подано нічого, вхід буде прочитано з консолі.

Якщо подано одне число n, буде зроблено список довжиною n зі значеннями 0..n-1.

Якщо подано список значень `"a -> b -> c -> d"` (будь-що з розділювачем `->`), буде використано саме його. Список треба брати в лапки, бо інакше `>` сприйметься оболонкою як перенаправлення.

## Запуск

### Спосіб 1: готовий файл

1. Завантажити з Releases `node-task` (Linux) або `node-task.exe` (Windows).
2. На Linux дати права на запуск: `chmod +x node-task`.
3. Запустити, напр. `./node-task 5` або `node-task.exe 5`.

### Спосіб 2: збірка через Cargo

1. Завантажити весь репозиторій (потрібен Rust 1.85 або новіший).
2. У кореневій теці виконати `cargo build -r --features cli`. Без `--features cli` виконуваний файл не збирається.
3. Програма буде в `target/release/node-task` (на Windows `node-task.exe`).

## Бібліотека

```rust
use node_task::TwoThirdsOfLinkedList;

let mut list = TwoThirdsOfLinkedList::new();
list.prepend_iter((0..5).rev()); // 0 -> 1 -> 2 -> 3 -> 4
assert_eq!(list.get_two_thirds_node().map(|n| n.data), Some(2));
```

`prepend` додає елемент на початок, тому значення подаються в зворотному порядку.

## Опис

Пошук іде за один прохід, O(n) за часом і O(1) за пам'яттю. Вказівник `res` стартує з голови, `curr` біжить списком до кінця. На кожному кроці `len` росте на 1, якщо `len mod 3 ≠ 1`, `res` теж переходить на наступний вузол. Для списку коротшого за 2 елементи повертається `None`.

Тести запускаються командою `cargo test`.
